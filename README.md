## About Elyra Budget

Elyra Budget is a native personal-finance app designed to make everyday budgeting simple, clear and flexible.

The app combines transactions, monthly budgets, category limits, fixed costs and savings goals in one modern interface.

Elyra Budget is currently being developed for iPhone. Dedicated versions for iPad and macOS are planned.

---

## Current Features

### Transactions

- Record expenses and income
- Add positive transactions and refunds
- Search and manage existing transactions
- Organize transactions by category
- Navigate between different months

### Budgets

- Set a monthly overall budget
- Create individual category limits
- View detailed budget information
- Track spending progress throughout the month
- Review previous and upcoming months

### Categories

- Create custom categories
- Choose individual icons and colors
- Organize expenses with flexible categories
- Archive categories without deleting their history

### Fixed Costs

- Create and manage recurring fixed costs
- Keep regular monthly expenses clearly organized
- Include fixed costs in personal budget planning

### Savings Goals

- Create individual savings goals
- Add deposits and withdrawals
- Track progress toward each goal
- Review the complete savings history

### Data and Sync

- Local data storage with SwiftData
- Private iCloud synchronization through CloudKit
- Automatic synchronization across supported Apple devices
- JSON backup and restore support

## Privacy

Elyra Budget is designed with privacy in mind.

Personal financial information is stored locally using SwiftData and synchronized through the user's private iCloud database. Financial data is not intended to be stored in a publicly accessible database.
